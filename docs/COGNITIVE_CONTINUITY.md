# Immutable Cognitive Continuity

EVEZ treats absence as state, not silence.

The continuity layer records ordinary cognitive nodes, missing parents,
unexplained temporal gaps, explicit tombstones, substitution lineage,
contradiction markers, and unresolved unknowns.

The important distinctions are:

    UNKNOWN
    we do not currently know this

    TOMBSTONED
    this existed and was removed or superseded

    TEMPORAL_ORPHAN
    this node declares a predecessor that is unavailable

    LINEAGE_BREAK
    adjacent timeline states lack a declared continuity edge

This prevents deletion or missing provenance from becoming false continuity.
