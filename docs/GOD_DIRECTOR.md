# G.O.D. Director and Living Reality Loop

G.O.D. means Generative Ontology Director.

It is a software role, not a religious or supernatural claim. Its job is to
choose the next useful, bounded information-producing operation from an explicit
candidate set.

The director sits above the persistent reality substrate:

intent
  -> candidate operations
  -> bounded selection
  -> world-state transition
  -> causal event
  -> replayable snapshot
  -> projection
  -> observation
  -> new event

The substrate deliberately separates five layers:

1. World state
   Addressable entities, relationships, attributes, provenance, and epistemic
   status.

2. Causal history
   Events declare causes, effects, actor, evidence, reversibility, and
   epistemic state.

3. Counterfactual space
   Hypotheses can branch into SIMULATED, COUNTERFACTUAL, or PROJECTED states
   without being represented as observations.

4. Cultural propagation
   Cultural units retain parent lineage while mutations remain explicit.

5. Self-model
   Predictions are compared with observations, producing error and resource
   efficiency telemetry.

The renderer is downstream from the world model.

One snapshot can therefore generate multiple projections without becoming
multiple incompatible sources of truth.

The director has a locked success criterion and self_authorization=false.
It cannot redefine success to make its own output look successful.

The useful "gift" is therefore not a claim about a deity. It is a compact,
replayable toy universe that can be inspected, branched, rendered, measured,
and evolved while retaining lineage.
