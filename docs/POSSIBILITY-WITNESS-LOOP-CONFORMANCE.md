# Conformance checklist: EVEZ Possibility–Witness Loop v1

- [ ] Schema rejects malformed or unsupported protocol version.
- [ ] Authenticated recipient matches requested recipient.
- [ ] Expiry and replay protection reject stale/duplicate handoffs.
- [ ] Missing capability is denied before invocation.
- [ ] Hypothesis/proposal cannot be recorded as direct observation.
- [ ] Input and output digest mismatch fails verification.
- [ ] Conflicting observations preserve both sources and open a resolution test.
- [ ] Verifier sees artifact and criteria independently from builder summary.
- [ ] Failed test blocks promotion to verified.
- [ ] Missing terminal receipt remains unknown/blocked.
- [ ] Read-only switch prevents all mutations at tool enforcement.
- [ ] Bounded retries stop at configured maximum.
- [ ] Ambiguous create/upload is reconciled by read before retry.
- [ ] External integrations are not declared connected on manifest alone.
- [ ] Spend, deployment, merge, permissions, secrets, and production require scoped human authorization.
- [ ] Report states exact tested/not-tested scope and residual uncertainty.
