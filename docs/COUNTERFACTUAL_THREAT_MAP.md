The counterfactual threat map separates anomaly from coordination.

ANOMALY != COORDINATION

An unusual burst can be produced by CI, Dependabot, retries, mirrored repositories, generated commits, or a single fast operator. Coordination evidence requires independent actors and independent sources in addition to a signal that survives a randomized null.

The null test shuffles actor labels while preserving event timestamps, text, and sources. The question is: does the observed actor alignment explain more structure than the same events with actor assignments randomized?

The detector therefore emits an explicit evidence state rather than a narrative. Missing columns remain missing evidence, not zeros. A single-source feed can flag an anomaly, but cannot establish cross-source coordination.

Guardrails: no motive inference, no identity attribution, no target generation, and no promotion of a cluster into an enemies list.

Operational path:
OBSERVED -> NULL TEST -> EVIDENCE STATE

not
OBSERVED -> STORY
