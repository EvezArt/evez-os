# Live Lexile Landscape

The browser surface at /dashboard/lexile/ is a local-first lexical amplifier.

It accepts explicit text, generates deterministic candidate lexical mutations,
maps layers and affective labels, and exposes the resulting frontier. It does
not access private mental state, hidden prompts, or external credentials.

The Python implementation is mobile/evez_lexile_landscape.py.

Operator examples:

    python mobile/evez_lexile_landscape.py "permaloot metamemetic emotion" --rounds 4
    evezctl lexile-live "permaloot metamemetic emotion" --rounds 4

All generated terms remain PROPOSED until independently supported.
