# Metamordia

Metamordia is the EVEZ operational name for a controlled representation change triggered by a persistent explanatory residual.

It is not a claim about literal quantum tunneling or physical translocation. The implementation requires a source frame, target frame, trigger, expected predictive distinction, test reference, and falsifier. A transition without those fields is not accepted as a testable leap.

The transition is content-hashed so the representation change itself becomes part of the evidence genealogy.
