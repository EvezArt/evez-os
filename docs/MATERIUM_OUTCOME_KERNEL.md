# Materium and Outcome Kernel

The execution kernel compiles user intention into a bounded outcome contract,
allocates finite resources, prepares an operator signal, and exposes the
authorization boundary.

Materium is the architecture name for finite resource accounting across
compute, memory, latency, energy, network, attention, and monetary budget. It
does not assert a physical theory.

Outcome compilation produces an objective, acceptance criteria, execution
stages, stop conditions, action class, and authorization requirement.

Consequential operations remain blocked without authorization. Verification is
separate from execution, and unverified results are never promoted to success.

Kernel states:

    READY_FOR_VERIFICATION
    AUTHORIZATION_REQUIRED
