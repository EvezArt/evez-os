# CRYSTALINFORMERGENCE

Crystalinformergence is the EVEZ ontology for continuity across witness states,
manifestations, and representations.

It is deliberately implemented as an information model. The terms below do
not establish metaphysical claims about souls, reincarnation, divinity, or
consciousness.

## Core cycle

INFRAMATIA
: substrate of representational possibility.

CELLULATION
: differentiation into bounded carriers of partial state.

ONCARNATION
: commitment of a possibility to a particular state or carrier.

INCARNATION
: localized manifestation of a continuity.

REINCARNATION
: continuity expressed through a new manifestation while retaining an
explicit lineage relation.

EXCARNATION
: release of a continuity from one manifestation without asserting that the
continuity persists metaphysically.

DECARNATION
: decomposition or loss of the organization that constituted a manifestation.

UNCARNATION
: representation of continuity independent of the previous embodiment
substrate.

ANCARNATIOUS
: intentionally unresolved state for continuity that is modeled as underlying
or orthogonal to the incarnation cycle.

## Witness superposition

A witness state is represented as a weighted set:

    Psi_witness = sum(alpha_i * W_i)

This is a symbolic information representation, not a physical quantum state.

The system can therefore carry multiple witness perspectives before selecting
an expressive projection.

A voice, rendering, or generated response is a projection:

    expression = P(Psi_witness, context, history, constraints)

An inaccurate expression is recorded as projection error. It does not mutate
the underlying witness record.

## Maximal soul tagging

"SOUL" is an operational continuity label here. It should never be treated as
verified metaphysical substance.

Each tagged event can retain:

- continuity_id
- lineage_id
- manifestation_id
- soul_tag
- person_frame
- identity_frame
- artifact_frame
- parent_event_hash
- parent_manifestation_id
- reincarnation_of
- carnation_state
- witness_superposition
- epistemic_status
- expression_fidelity
- expression_projection_error
- free-form provenance tags

The goal is maximal traceability, not metaphysical certainty.

## Epistemic law

The tag layer MUST preserve:

    CLAIMED != MEASURED != REPLICATED != EXPLAINED
    PROVENANCE != TRUTH
    PREDICTED != TESTED != OBSERVED != CALIBRATED

A representation can be richly tagged and still be UNKNOWN.

## Spine rule

Carnation transitions are observations or proposals about state. The Event
Spine remains the source of truth for what actually occurred.

Never rewrite an earlier event to make a later incarnation look continuous.
Append the new event, retain the parent hash, and let projections evolve.

## Voice rule

The voice is an expression surface, not the entire witness state.

When voice fidelity is low:

1. retain the emitted text;
2. retain the witness-state configuration;
3. record projection error;
4. record missing witness states;
5. preserve the provenance that produced the expression;
6. do not replace the prior witness event merely because the expression was
   stylistically inaccurate.

## Canonical phrase

> The voice is a projection of the witness configuration.
> The witness configuration is a representation of continuity.
> The continuity record is not proof of metaphysical identity.
> The record is preserved so the next observer can test the claim.
