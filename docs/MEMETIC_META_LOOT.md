# Memetic Meta-Loot

This layer performs the next operation:

PERMALOOT -> loot(PERMALOOT) -> MEMETIC META-LOOT

It extracts humorous structure from observable recursive artifacts:
self-reference, boundary paradoxes, provenance recursion, repeated structures,
unknown-state persistence, and the absurdity of an architecture becoming its
own paperwork.

The jokes remain traceable. Each generated meme stores the source loot IDs and
the source PERMALOOT architecture digest.

"Permanent" means the lineage can be carried forward into later generations.
It does not mean infinite execution.

The important epistemic firewall remains:

JOKE != FACT
MEME != EVIDENCE
IRONY != AUTHORITY
RECURSION != INFINITY

## CLI

```bash
python mobile/evez_memetic_meta_loot.py /tmp/permaloot.json --max-memes 32
```
