# Rights and Licensing Control Plane

This directory separates three different questions:

1. **What rights are declared?**
2. **What rights can the project actually grant?**
3. **What commercial pathways could use those rights?**

The system must never infer ownership from the existence of a file.

SPDX provides standardized machine-readable license identifiers and a common
license list. OSI maintains the canonical list of OSI Approved Licenses. Both are
reference sources, not proof that EVEZ owns every asset in this repository.

The license opportunity auditor therefore uses an ownership-first rule:

    UNDECLARED -> REVIEW
    DECLARED -> CANDIDATE
    THIRD_PARTY -> PRESERVE
    OWNERSHIP_UNKNOWN -> DO NOT GRANT

Commercial opportunity classes include hosted service, support, enterprise
integration, commercial licensing of newly created rights, media licensing,
syndication, training, publication, and data licensing.

A commercial opportunity is not a prediction of revenue.

## Lexile boundary

EVEZ may compute an internal reading-complexity proxy, but that output must not
be represented as a certified Lexile measure. MetaMetrics describes certified
Lexile measures as distinct from ranges generated by its tools, and its current
documentation states that Hub-generated measures are not certified and are not
for commercial use or personal gain.

The EVEZ mapper therefore produces:

    INTERNAL_PROXY_NOT_CERTIFIED_LEXILE

It does not copy or reconstruct the proprietary Lexile scoring system.
